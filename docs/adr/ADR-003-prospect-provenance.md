# ADR-003 — Prospect evidence provenance

**Decision:** material prospect assertions must be classifiable as public observed, public third-party, AI assessment, owner verified, system measured, or unknown. Evidence records carry source references and storage policy.

**Why:** sales trust depends on distinguishing measured fact from inference and protecting provider/data terms.

**Escape hatch:** raw evidence may be stored only when rights/terms and security policy explicitly permit it.
